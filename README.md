# Final_project_brownian-motion
Aisha Kerim's and Amina Abek's final group project for Introduction to Numerical algorithms class

We will simulate random walks in two and three dimensions using Python and investigate how particles spread over time.

We plan to(it may change as we work on this project):

1)Visualize particle trajectories.

2)Study average distance and mean squared displacement.

3)Analyze particle-position distributions.

3)Compare simulation results with theoretical predictions.

Planned methods: Monte Carlo simulation, least-squares fitting and kernel density estimation.

Tools: Python, NumPy, SciPy and Matplotlib.
